Sobre o Projeto

Objetivo do Trabalho

Este trabalho tem como objetivo aplicar os fundamentos de desenvolvimento de software por meio de duas atividades práticas complementares:

  1. Lista 1 – Lógica de Programação com Portugol
    Desenvolvimento de algoritmos na ferramenta Portugol.dev para resolver problemas como sistemas de cadastro, cálculo de vendas e manipulação de vetores.
  2. Lista 2 – Criação de Página Web com HTML e CSS
    Construção de uma página web que apresente informações sobre a equipe e o projeto, aplicando HTML semântico, layout organizado e estilização com CSS.

Atividades Desenvolvidas

  • Lista 1 – Exercícios em Portugol: Cadastro de usuário; cálculo de vendas em padaria; aplicação de desconto; cadastro e análise de pacientes; contagem de valores pares em vetor; soma de dois vetores.
  • Lista 2 – Página Web: cabeçalho com título e menu; seção de integrantes (foto, descrição, redes sociais); tabela de tarefas (nome, RU, contribuição); descrição do projeto; rodapé com contato e créditos.

Tecnologias Utilizadas

  • HTML5 – Estruturação do conteúdo.
  • CSS3 – Estilização visual e layout.
  • Portugol.dev – Desenvolvimento e teste de algoritmos.
  • Codepen / GitHub Pages – Hospedagem e compartilhamento da página web.
